Introducing GNG Browser

Automation today is scattered across windows. One browser per account, a guess every time about which window is who, and the scripts running somewhere else entirely.

GNG Browser puts all of it back in one place. Every tab is an account, and the agent works inside that tab. It drives the screens you are already signed in to, and hands the heavier jobs to the services you already run.

The app isn’t code-signed, so the first launch shows a warning. Here’s how to get past it.

macOS says the app can’t be opened

Right-click GNG Browser in Applications and choose Open, then Open again in the dialog. If macOS still refuses, run xattr -dr com.apple.quarantine "/Applications/GNG Browser.app" in Terminal. Either way, only once.

Windows SmartScreen blocks the installer

Click “More info”, then “Run anyway”. SmartScreen flags any installer it hasn’t seen signed before.

네이버 계정마다 세션을 따로 두는 브라우저예요.
오른쪽 패널에 적으면 에이전트가 그 탭에서 움직여요.

Playwright 가 CDP 로 그대로 붙어요. 로그인이 살아 있는 실제 브라우저에서 네이버 작업을 돌리는 개인용 도구예요.

이렇게 시켜요

네이버 자동화는 로그인이 살아 있는 실제 브라우저에서 돌려야 결과가 맞아요. 그동안은 계정마다 브라우저 프로필을 따로 띄우고 스크립트로 붙었는데, 창 관리가 바깥에 있어서 어느 창이 어느 계정인지 매번 확인해야 했어요.

Ply 는 프로필 관리와 CDP 연결을 한 앱에 넣었어요. 계정 하나가 세션 하나고, 쓰던 Playwright 스크립트는 같은 CDP 주소에 붙어서 그 탭을 그대로 다뤄요.

패널에 적으면 도구를 골라 실행해요.
모자란 값은 지어내지 않고 되물어요.

도구 34개

로그인, 원고 생성, 블로그 발행과 삭제, 예약 발행, 노출체크, 카페 가입과 댓글, 쇼핑몰 로그인까지 도구 34개예요. 원고 스타일이나 날짜, 계정처럼 정할 게 남으면 입력 카드를 띄워요.

계정 하나가 세션 하나

계정을 등록하면 그 계정만의 세션이 생겨요. 쿠키와 저장소가 갈려서 다른 계정과 섞이지 않아요. 에이전트가 연 탭은 사이드바에 따로 모여요.

쓰던 스크립트는 그대로

기본 CDP 포트는 18830 이에요. connectOverCDP 주소만 바꾸면 돼요. 포트는 PLY_CDP_PORT 로 바꾸고, 0 이면 꺼요.

chromium.connectOverCDP('http://127.0.0.1:18830')

이건 안 해요.

  • 캡차와 2차 인증은 안 풀어요. 탭을 남겨 두고 직접 마치라고 알려요.
  • 한 번에 작업 하나만 돌아요. 도는 중에 시키면 거절해요.
  • OpenRouter 키가 있어야 해요. 첫 화면에서 키부터 받아요.
  • Linux 는 안 해요. macOS 와 Windows 만 빌드해요.

되돌릴 수 없는 일은 코드로 막아요.
네이버는 복구를 지원하지 않아요.

지우기 전에 확인 카드

제목과 작성일, 글 번호를 보여주고 정해진 승인 문구를 적어야 지워요. 다른 답은 전부 취소예요.

목록에서 읽은 글만

같은 실행에서 목록으로 읽은 글 번호만 받아요. 그 밖의 번호는 코드가 거절해요. 한 번에 최대 10건이에요.

정지 버튼

누르면 하던 작업 하나가 끝나면 멈춰요. 돌고 있는 도구 하나는 끝까지 돌아요.

비밀번호는 이 컴퓨터에만

카드로 받아서 macOS 는 키체인, Windows 는 DPAPI 로 암호화해 둬요. 입력은 선택이라 비워 두면 로그인 창에서 직접 넣어요.

받아서 열고, 키부터 넣어요.

macOS

Apple Silicon 과 Intel

현재 기기
Apple Silicon Intel

어느 쪽인지 모르면 애플 메뉴에서 이 Mac에 관하여를 열어요. 칩 이름이 Apple M 이면 Apple Silicon 이에요. 반대쪽을 받으면 설치는 되고 실행만 안 돼요.

Windows

Windows 10 또는 11, 64비트

현재 기기
설치 파일 (.exe)

설치 위치는 고를 수 있어요.

아직 올라온 빌드가 없어요. 소스에서 npm ci 뒤 npm run dist 로 빌드해요.

전체 릴리스 소스 코드 면책 안내

코드 서명이 없어서 처음 열 때 경고가 떠요. 넘기는 방법이에요.

macOS

터미널에서 xattr -dr com.apple.quarantine "/Applications/Ply.app" 을 실행해요. 아니면 한 번 열어 경고를 띄운 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 그래도 열기를 눌러요. macOS 15 부터는 우클릭 → 열기로는 안 넘어가요.

Windows

SmartScreen 창에서 추가 정보를 누르고 실행을 눌러요.

첫 실행은 패널을 열고(◧ 또는 ⌘J / Ctrl+J) OpenRouter 키를 넣은 뒤 모델을 고르고 네이버 계정을 추가하는 순서예요. 키 발급받기 버튼은 OpenRouter 로그인과 이메일 인증까지는 대신하지 않아서 몇 분 걸릴 수 있어요.

Ply GitHub 면책 안내

이 앱은 네이버에 자동으로 로그인하고 글을 쓰고 지워요. 자동화는 약관에 걸릴 수 있고 계정 제재로 이어질 수 있어요. 위험은 사용자가 져요. MIT 라이선스이고 아무 보증도 없어요.
